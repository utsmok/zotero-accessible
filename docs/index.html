Zotero Accessible Setup

One download sets up Zotero on a new computer. You install it once, and everything below is done for you:

  • Much larger text everywhere (70% bigger than the Zotero default), also in notes
  • High contrast colors: black text, and the selected item shown as a black row with white text
  • Only three columns in the item list: Title, Creator, Year; item details show only fields that have content
  • Collections: 00 Inbox, 01 Method, 02 Topic X, 03 Topic Y
  • Everything you save from the browser lands in 00 Inbox with the tag "To read", and a large message in the middle of the screen confirms it
  • Three colored tags: To read (red), Reading (orange), Read (green). Big buttons above the item list, or the keys 1, 2, 3, add or remove them. The whole row takes the tag's color
  • Opening a PDF moves it from "To read" to "Reading"; a Mark as Read button in the PDF toolbar finishes it
  • PDFs and saved web pages open in Reading Mode: one narrow column of plain text with wide line spacing. Cmd+Shift+M switches back to the original pages
  • A Focus view button that hides the side panes, so only the item list is left
  • A saved search called "To read" that lists everything unread, and no automatic tag clutter from websites

Options in the View menu, at the bottom: Focus View, Open PDFs in Reading Mode, Low-Glare Colors (cream instead of white, for days when bright screens hurt), and Show Empty Fields in Item Details (to fill in a missing field).

Step 1: Download the file

Download the setup file

The file is called zotero-accessible-setup.xpi. It usually lands in the Downloads folder.

Step 2: Install it in Zotero

Do this after Zotero is installed and opened once:

  1. Open Zotero.
  2. In the menu bar, click Tools, then Plugins.
  3. In the Plugins window, click the gear button at the top right.
  4. Click Install Plugin From File…
  5. Choose the downloaded .xpi file and confirm.

The changes appear right away; no restart is needed. You should see larger text, the four collections on the left, and the three colored tags at the bottom left.

The plugin updates itself. If you installed an earlier version, open Tools > Plugins, click the gear button, and click Check for Updates to get the newest one now.

Step 3: Print the cheat sheet

The cheat sheet has the most important keys and the five most common tasks, written out step by step.

  1. Open the cheat sheet page.
  2. Press Cmd+P to print it. The text is already large.

Three things only you can do

  1. Zotero account: in Zotero, open Settings > Account and sign in or create an account. This syncs your library.
  2. Browser connector: for Safari, the connector comes with Zotero; turn it on in Safari > Settings > Extensions. For Chrome, install the Zotero Connector from zotero.org/download.
  3. Mac settings: System Settings > Appearance > Light, and Accessibility > Increase contrast on. Zotero copies the Mac's look.

For the iPad: install the free Zotero app from the App Store and sign in with the same account. When you save from Safari on the iPad with the Share button, choose 00 Inbox as the collection; the plugin only works on the Mac.

Optional: tidy titles and author names automatically

Websites often save titles in CAPITALS or with odd spelling. The free plugin Linter for Zotero fixes this when an item is saved: titles in normal sentence case, author names with normal capitals, and missing DOIs filled in. Install it the same way as the setup file:

  1. Download linter-for-zotero.xpi.
  2. In Zotero, open Tools > Plugins, click the gear button, click Install Plugin From File…, and choose the file.

Mac settings that help in every app

These are optional. Try them one at a time; each works in Zotero, the browser, and Word. All are in System Settings > Accessibility.

  • Hover Text: turn it on, then hold Cmd while pointing at any text to see it very large in a box. It enlarges one line without zooming the whole screen, so the rest stays where it was.
  • Display > Pointer: make the pointer larger, give it a bright outline color, and turn on Shake mouse pointer to locate. A wiggle on the trackpad then makes the pointer big for a moment.
  • Display: Increase contrast and Reduce transparency on. Both remove pale, see-through backgrounds.
  • Read & Speak: turn on Speak selection. Select any text and press Option+Esc to hear it.
  • Zoom: if you want a magnifier, choose the Picture-in-picture zoom style. It magnifies a box around the pointer and keeps the rest of the screen in place.

On the iPad, Settings > Accessibility > Per-App Settings lets you make text larger in the Zotero app only. In the Zotero app's PDF reader, the Aa button sets the text size.

Questions or changes?

Text too large or too small? Use View > Font Size in Zotero. Want different colors or other collection names? Ask Sam; the setup is one small plugin and easy to adjust.
