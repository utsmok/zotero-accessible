Zotero Accessible Setup

One download sets up Zotero on a new computer. You install it once, restart Zotero, and everything below is done for you:

  • Larger text everywhere
  • High contrast colors
  • Collections: 00 Inbox, 01 Method, 02 Topic X, 03 Topic Y
  • Tags with colors and number keys: 1 = To read, 2 = Reading, 3 = Read
  • A saved search called "To read" that lists everything unread
  • No automatic tag clutter from websites

Step 1: Download the file

Download the setup file

The file is called zotero-accessible-setup-1.0.0.xpi. Remember where it lands, usually the Downloads folder.

Step 2: Install it in Zotero

Do this after Zotero is installed and opened once:

  1. Open Zotero.
  2. In the menu bar, click Tools, then Plugins.
  3. In the Plugins window, click the gear button at the top right.
  4. Click Install Plugin From File…
  5. Choose the downloaded .xpi file and confirm.
  6. Restart Zotero when it offers to. Done.

After the restart you should see the four collections on the left and the three colored tags at the bottom left, and the text should be larger.

Step 3: Print the cheat sheet

The cheat sheet has the most important keys and the five most common tasks, written out step by step.

  1. Open the cheat sheet page.
  2. Press Cmd+P to print it. The text is already large.

Three things only you can do

  1. Zotero account: in Zotero, open Settings > Account and sign in or create an account. This syncs your library.
  2. Browser connector: on the Mac, install the Zotero Connector for Safari or Chrome from zotero.org/download.
  3. Mac settings: System Settings > Appearance > Light, and Accessibility > Increase contrast on. Zotero copies the Mac's look.

For the iPad: install the free Zotero app from the App Store and sign in with the same account.

Questions or changes?

Want different colors, other collection names, or a different text size? Ask Sam. The setup is one small plugin and it is easy to adjust.
